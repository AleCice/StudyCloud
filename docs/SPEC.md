# Specifiche StudyCloud

Applicazione PWA per studenti universitari per gestire file, organizzare appunti e interagire con un AI per studio e ripasso.

## Funzionalità Principali
- Sincronizzazione cloud (Supabase)
- Chat RAG su documenti personali
- Assistente vocale
- Tutor AI
- PWA installabile cross-platform

Il tutto con budget controllato e fallback a modelli AI economici.
