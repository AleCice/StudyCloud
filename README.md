# StudyCloud

Applicazione web/PWA cloud-first per l'organizzazione e lo studio personale. Offre upload, sincronizzazione file, gestione tramite database vettoriale e assistenti AI.

## Tecnologie

- **Frontend**: Next.js App Router, Tailwind CSS, TypeScript
- **Backend/DB**: Supabase (PostgreSQL, pgvector, Storage, Auth)
- **AI**: Vercel AI SDK

Vedi la cartella `docs/` per specifiche, task e architettura dettagliata.
